# Game01 Tetris Game

This project is a simple implementation of the classic Tetris game using HTML5, CSS3, and JavaScript.

## Project Structure

- `index.html`: The main HTML structure of the game, including the game canvas and UI elements, and links to CSS and JavaScript files.
- `css/style.css`: The stylesheet that defines the game's styles, including the design for the canvas, blocks, background, and other UI elements.
- `js/game.js`: Contains the main logic of the game, handling initialization, updates, rendering, and user input.
- `js/pieces.js`: Defines the Tetris pieces, including their shapes, rotation logic, and handling piece creation and movement.
- `js/board.js`: Manages the state of the game board, including the grid, collision detection, and line clearing logic.

## Installation

1. Clone the repository or download the project files.
2. Open `index.html` in a web browser.

## Usage

- Use the arrow keys to move and rotate the Tetris pieces.
- The game ends when the pieces stack to the top of the canvas.

Enjoy playing Tetris!
